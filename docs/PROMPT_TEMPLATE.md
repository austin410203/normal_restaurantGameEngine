# 開新遊戲的提示詞範本

複製下面整段，把【】裡的內容換成你的新遊戲，再貼給 Claude。

---

這個 repo 是我的經營模擬遊戲模板。請先讀 `CLAUDE.md`，只打開完成任務需要的檔案，不要掃描整個 repo。

我要用它做一款新遊戲：

- 遊戲名稱：【例：拉麵大作戰 / Ramen Rush】
- 店的類型與場景：【例：夜市拉麵攤，顧客坐在吧台，不是開車】
- 可點的餐點：【例：豚骨拉麵、味噌拉麵、煎餃、烏龍茶】
- 每道餐點的做法：【例：豚骨拉麵＝麵條→煮麵鍋 4 秒＋湯頭→組裝台＋叉燒】
- 工作站：【例：食材櫃×4、煮麵鍋×2、湯鍋、煎台、飲料機、組裝台、出餐口、垃圾桶】
- 8 關的難度走向：【例：第 1 關只有拉麵；第 3 關加入下雨；第 6 關 VIP 美食評論家…】
- 視覺風格與配色：【例：暖黃燈籠、木頭色、紅色招牌】
- 要保留的現有功能：中英文切換、白天/晚上、手機版、選關、Vercel 部署
- 3D 物件：用 `tools/blender` 新增【新食物／新工作站／新角色】的模型，跑 `npm run models`

完成後請：執行 typecheck、測試、build，用手機和電腦尺寸各截一張圖確認畫面，最後推到【GitHub repo 網址】。
